# NERIVO autonomous plan

- Ollama
- gpt-oss:20b benchmark
- persistent SQLite audit log
- watchdog / restart

## Phase B — business tools
- Brevo: lead/contact operations
- Stripe: revenue/subscription read-only metrics
- GitHub: repository/issues/PR workflow
- Vercel: deployment/health workflow
- dedicated NERIVO email account via IMAP/SMTP

## Phase C — operating loops
- lead qualification
- customer support triage
- follow-up drafting
- daily sales analysis
- product backlog
- bug triage
- release preparation
- weekly growth experiments

## Phase D — controlled autonomy
Automatic:
- analysis
- reports
- drafts
- tests
- reversible repository changes in a sandbox

Approval required:
- public customer messages until quality is proven
- production deploys
- financial actions
- refunds
- deleting data
- legal/contractual commitments
- bulk outreach

## Owner dashboard
Daily brief should contain:
- cash/revenue metrics
- new leads
- qualified leads
- conversions
- customer issues
- product changes
- errors
- actions requiring approval
- next 24h priorities
